Astuces

Utiliser d’abord l’annuaire des laboratoires IIS pour retrouver rapidement un chercheur, un laboratoire ou une page de département.

Pour vérifier une affiliation officielle, privilégier les profils IIS : ils listent les départements, centres et systèmes éducatifs.

Utiliser les liens RCAST et EEIS pour replacer le laboratoire dans son contexte institutionnel hors IIS.

Ouvrir les liens externes dans un nouvel onglet afin de garder le site du laboratoire comme point de navigation.
